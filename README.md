# Argon 4 Style "AI" Interactive WebGL Hero (Next.js 14)

An interactive WebGL fluid-refraction and frosted aerogel typography hero section inspired by Google's **Gemini 4 Argon** artwork. Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Inter Black (900)**.

## ✨ Features
- **Exact Argon 4 Palette**: Deep midnight sapphire (`#010926`) to electric royal azure (`#1D6CE0`) to solar icy cyan-white (`#D8F6FF` / `#FFFFFF`).
- **Frosted Aerogel GLSL Shader**: Multi-channel SDF/blur offscreen typography mask refracted with 4-octave Simplex FBM noise, 3D inner bevel lighting, and subtle chromatic dispersion.
- **Interactive Mouse Wake & Vortex Spores**: Real-time 2D velocity dissipation buffer and radial vortex micro-particles that react smoothly to mouse hover and touch.

## 🚀 Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploying to GitHub & Vercel

1. **Initialize Git & Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial Argon 4 AI interactive WebGL hero"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
2. **Deploy on Vercel**:
   - Go to [https://vercel.com/new](https://vercel.com/new)
   - Import your GitHub repository
   - Click **Deploy** (zero additional configuration needed!)
